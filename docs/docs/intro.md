# Welcome to Campus Study Buddy Docs

Let's discover **Campus Buddy in less than 5 minutes**.

## About the Project

A platform that helps students **find study partners**, **join study groups**, **schedule group sessions**, and **track topics** they have covered. It is university community forum / social media to help students improve their experience with university work.

### Core Features

- **Find study partners**
  - Match with other students based on shared modules or topics.
  - View profiles of students in your course.
- **Create study groups**
  - Create and join group sessions.
  - Chat, share notes, and set group goals.
- **Track your progress**
  - Log any completed topics, chapters, and sections.
  - Track and view your hours spent studying.
- **Plan sessions**
  - Schedule future study sessions with reminders.

### User Interface (UI) Pages

- Dashboard 
    - Summary information, upcoming events, new groups, etc.
- User Profiles
- Study Partner Search
- Group Session Planner
- Progress Tracker with tables and charts
- Chat Window

### Application Programming Interface (API) Modules

- Partner Matching API 
    - CRUD (Create, read, update and delete) and search on user preferences and profiles
- Group Session API 
    - CRUD for groups, members, and scheduling
- Progress API 
    - CRUD for topics, completion state, and hour tracking
- Notifications API 
    - Manage reminders and updates

### Database (DB) Entities

- User Profiles
- Study Groups
- Topics, Chapters, Other Material
- Notifications and Reminders
